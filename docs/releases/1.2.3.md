Anri Logger 首个公开发行版本，适用于 Minecraft 26.1.2 / Fabric。用于记录和查询玩家方块操作与容器物品存取，客户端无需安装。

## 功能

- 记录方块破坏、放置、使用及其引起的连带变化，每次玩家操作最多记录 10 次连带方块变化。
- 记录容器打开、物品存入与取出，保留物品 ID、数量、组件和真实操作位置。
- `/al inspect` 检查方块历史，`/al container` 查询物品存取，`/al search` 筛选并分页查询历史。
- 双箱查询合并两侧记录，修复点击一半时漏显另一半物品存取的问题。
- 可选兼容 Carpet TIS Addition 的 `largeBarrel`：仅在 TIS 已安装且规则启用时合并大木桶两侧查询，支持水平与垂直连接。TIS 不是本模组的前置依赖。
- 历史保存在单个压缩的 `config/anri-logger/history.db` 中，支持原有数据库记录的继续查询。
- 本项目使用 MIT 协议，第三方组件保留各自的许可证。

## 安装

需要 Java 25、Minecraft **26.1.2**、Fabric Loader **0.19.3 或更高版本**及适用于 26.1.2 的 Fabric API。

将 **`anri-logger-1.2.3+mc26.1.2.jar`** 放入服务端 `mods/`。`-sources.jar` 供开发者阅读源码，不要放入 `mods/`。H2 MVStore 已内嵌，无须额外下载数据库驱动。

从已有 1.2.x 测试版本升级时，正常停服后替换 JAR，保留配置及数据库即可。使用更早版本时请先阅读 README 中的格式升级说明。

## 验证与附件

发布前通过 24 项单元测试和 14 项服务端 GameTest。大木桶兼容此前已使用 `carpet-tis-addition-v1.82.0-mc26.1.2.jar` 进行实际联动验证，覆盖规则开启、关闭、三个连接轴及两侧查询。

附件提供安装 JAR、源码 JAR 和 `SHA256SUMS.txt` 校验文件。完整使用方法、配置与查询限制见仓库 README。
